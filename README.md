# iTANTRA UI Demo

Premium Jetpack Compose UI prototype for the iTANTRA concept.

## Open
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Run the `app` configuration on an Android emulator or device.

## Included
- Sender/home screen
- PTT interaction
- English language selector
- Offline + connection status
- STT → Secure → Wireless status
- Emergency alert screen
- Messages
- Settings
- Bottom navigation

This is a UI prototype. It does not yet implement real STT, TTS, encryption, Bluetooth/Wi-Fi transport, or AudioManager emergency behavior.
